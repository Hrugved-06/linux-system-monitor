# Linux System Information Monitor

## Internship Task 2: Core Concepts and Skills

### Objective
To practice Linux commands and create a Bash script
that displays basic system information.

### Tools Used
- Ubuntu Linux (WSL)
- Bash
- Git
- GitHub

### Features
- Displays date and time
- Displays hostname and operating system
- Shows system uptime
- Displays disk and memory usage
- Displays the system IP address

### How to Run
1. Open the project directory.
2. Make the script executable:
   chmod +x system_info.sh
3. Run the script:
   ./system_info.sh

### Learning Outcomes
Practiced Linux commands, file permissions, networking,
system monitoring, and Bash scripting.
